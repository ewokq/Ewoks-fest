# FESTIVAL CONTROL v2.3.1: Roadmap / spec coverage

This file covers every section of SPEC.txt (34 sections). Legend: ✅ done · 🟡 partial (the alternative used is listed) · ⏳ deferred.
Platform: one self-contained HTML5 file (Three.js r160 + Web Audio), touch-first for iPhone Safari (portrait and landscape, safe areas), with desktop keyboard and mouse. The old v1.4 game is still playable at `/classic/`.

**v2.3 (fun layer + 1v1):** these features came from rhythm and casual game research: combo multipliers with a capped, forgiving FEVER (Pick a Beat scoring), Wordle-style daily seeded runs with streaks and spoiler-free sharing, star ratings and achievements for replay goals, and local versus play. HYPE ×1–×4 multiplier, FEVER (8 bars ×2), crowd requests, 1–5 stars, 13 achievements, Daily Festival with streak and share, 1v1 same-device split-screen duel (portrait and landscape, keyboard and touch, rematch), duel links with a head-to-head table, 4 harder EDM tracks (CC BY / CC BY-NC 3.0), save format v2 with automatic migration, and tests in `test/v23.js`. Not done: online real-time duels over WebRTC (needs a signalling server; links and same-device play cover it).

**v2.1 (user friendliness + living crowd):** new main menu with a big PLAY button (a random track at Horizon Mainstage, assisted, short); a first-launch welcome and guided show; a Simple console by default (12 big labelled pads: Colors, Looks, LED, Lasers, Flash, Strobe, Blackout, CO2, Flames, Confetti, Fireworks, DROP!) with a Pro toggle for the full 7-tab console; hints, a drop countdown (DROP IN N BARS → 4·3·2·1), glowing suggested pads, PERFECT/GREAT/PERFECT DROP! popups and combos, haptics, sounds; auto-arming pyro in Simple mode; an 8-step tutorial with a pointer ring; touch targets ≥48px, checked by automated clipping tests in portrait, landscape and desktop; cache-busting meta tags, `?v=` asset queries and an in-game "new version" banner. Crowd: instanced human figures animated per person (own beat phase, head nods, fist pumps, build-up claps, unison drop jumps, breakdown sway with phones), circle pits for heavy genres, shoulder riders, flags and totems, glowsticks, cheer bursts and energy waves from front to back, crowd audio, confetti that lands on the crowd, near/far LOD, and a close-up "faces" camera.

## My Song (YouTube): audio-only mode
- Paste a YouTube link. The video plays through the official IFrame API with the picture hidden (audio only).
- **Limitation:** browsers don't let a page analyse the audio of a cross-origin YouTube iframe. Auto BPM instead uses (a) the microphone (it listens to the speaker output, on-device tempo estimation) when permission is granted, or (b) manual BPM, TAP tempo, SYNC to the downbeat, nudge, and mark-drop.
- Sections and drops come from the beat grid plus the drops you mark.
- Scoring works on the beat grid.

## Deferred
- Real-time shadows; true volumetric light (raymarched).
- Persistent replay library; video export.
- Multiplayer; DMX/Art-Net output; VR; mod workshop.
