# FESTIVAL CONTROL v2.0

You are the lighting and show operator of an EDM festival mainstage. Run the moving lights, lasers, LED walls, haze and simulated pyro live to a procedural EDM set, keep the crowd hyped, and get scored like a real show operator.

**Play:** https://ewokq.github.io/Ewoks-fest/ (works on iPhone Safari in portrait or landscape, and on desktop)
**Old game (v1.4 Drop Control 3D):** https://ewokq.github.io/Ewoks-fest/classic/

- Modes: Career (7 venues and a shop), Show, Free Play sandbox, Challenges, Tutorial, My Song (YouTube, audio only, Auto BPM)
- Desktop keys: Space play/pause · Q console · E FX · R LED · Tab dashboard · J flash · L strobe · K blackout · Enter GO · P arm pyro · T/Y/N/M/G pyro · 1–8 groups · V camera · Esc menu
- See ROADMAP.md for spec coverage and limitations.

All artists, tracks, venues and gear are fictional.
